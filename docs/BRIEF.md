# Brief: single page Hyper.Parts (fonte: pagina Notion "Hyper.Parts", Due.Zero)

Landing informativa di un servizio gestito (NON SaaS self-service) per la gestione di ricambi/parti. Pubblico: costruttori di macchinari, service/post-vendita interno, manutenzione in campo, pianificazione. Lingua: italiano.

## Stack (vincolante)
Single page statica, nessun framework, nessun build: un solo file `index.html` con HTML/CSS/JS vanilla. Nessun backend.
